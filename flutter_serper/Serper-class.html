Serper

Serper class

A wrapper for the Serper API.

Provides methods for all supported Serper API endpoints, including search, images, videos, places, maps, reviews, news, shopping, lens, scholar, patents, autocomplete, and webpage scraping.

All methods use the Dio HTTP client and return strongly-typed response objects that extend SerperResponse, allowing for polymorphic handling of responses.

Example usage:

final serper = Serper(apiKey: 'your-api-key');
final searchResults = await serper.search([SearchQuery(q: 'coffee shop')]);
print(searchResults.organic.length);
